# textlab-hackathon

Plataforma web en Streamlit para diseñar, entrenar, evaluar, comparar y usar modelos de clasificación supervisada de textos sin fuga de información.

## URL de la aplicación
https://textlab-hackathon-2qpd9lyspwo4kcrf5zrhft.streamlit.app

## Dependencias
Incluidas en `requirements.txt` (Streamlit, Scikit-learn, Pandas, NumPy, Plotly, NLTK).

## Instrucciones de ejecución
```bash
pip install -r requirements.txt
streamlit run app.py
